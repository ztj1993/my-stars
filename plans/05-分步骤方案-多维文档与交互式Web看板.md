# 05 - 分步骤方案：多维文档与交互式 Web 看板

## 1. 目标

提供两种互补的知识库呈现形式：
1. **GitHub 风格 Markdown 体系**：静态托管在 GitHub 仓库，便于直接在 Web 端阅读与导航。
2. **交互式 Web 看板（`index.html`）**：单文件轻量化应用，支持极速秒搜、多级过滤与卡片/表格视图切换。

---

## 2. Markdown 文档体系设计

### 2.1 根目录 [`README.md`](../README.md)
- **统计徽章**：包含 Star 总数、分类总数、更新日期、看板入口。
- **大盘表格**：10 大领域一级分类及各自分类下包含的二级子类列表与项目数。
- **技术栈分布**：Top 10 编程语言占比。
- **高星标杆榜单**：展示 Top 15 最受欢迎的高星项目卡片。

### 2.2 10 大专题文档（`docs/categories/*.md`）
- 每个专题文档按**二级子类**进行分章节编排。
- 提供页内快速目录导航（Anchor links）。
- 格式规范：
  ```markdown
  ### 1. [项目名称](项目链接)
  - **⭐ Stars**: `12,345` | **二级分类**: 🐳 `Docker 与容器管理` | **语言**: `Go`
  - **🏷️ 标签**: `Go` `Docker` `CLI`
  - **📝 中文介绍**: 项目的精准中文功能描述。
  - **✨ 核心功能与亮点**:
    - 特性 1 ...
    - 特性 2 ...
  ```

---

## 3. 交互式 Web 看板架构（[`index.html`](../index.html)）

### 3.1 架构与技术栈
- **驱动框架**：Alpine.js（超轻量级声明式响应式框架，无打包依赖）。
- **样式与设计**：Tailwind CSS CDN + 自定义暗色模式（Dark Mode）。
- **图标系统**：FontAwesome 6。
- **数据源**：直接内嵌 `data/enriched_stars.json`，纯前端运行，支持离线与本地直接双击打开。

### 3.2 核心交互能力
1. **全局实时搜索**：支持对项目名、中文描述、二级分类、亮点、标签、语言进行不区分大小写的模糊搜索。
2. **两级分类级联过滤**：
   - 顶部一级领域过滤 Tab。
   - 点击一级领域后，展开该领域专属的二级细分子类胶囊按钮。
3. **多维排序**：按 Star 数（高→低/低→高）、Star 收藏时间（最新优先）、仓库更新时间、名称（A-Z）。
4. **双视图模式**：
   - **卡片视图（Grid）**：图文卡片，高亮特性列表与标签。
   - **紧凑表格视图（Table）**：高密度展示，适合快速扫视。
5. **分页控制**：每页 48 条，平滑换页。
